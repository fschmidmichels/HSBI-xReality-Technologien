# Woche 1: Ergebnisse – XR erleben und Gestaltungskriterien entwickeln

## Station 1 – First Encounters

| Feld | Eintrag |
| --- | --- |
| Anwendung und untersuchte Situation | Niedliche Aliens einsammeln |
| Eingabeform und verwendete Funktion | Controller, Trigger-Taste |
| Konkrete Beobachtung: Welche Handlung wurde ausgeführt, und welche Reaktion wurde wahrgenommen? | Controller wird zu Pistole, Aliens werden "eingesammelt" |
| Handlungsmöglichkeiten: Wodurch wurde die mögliche Aktion erkennbar gemacht? | Projektile, Beschreibung wird angezeigt, Aufheben oder Schießen nicht erklärt |
| Feedback: Welche visuellen, akustischen oder haptischen Rückmeldungen wurden gegeben? | Visuell: Score, Projektile, Animation der Aliens; Akustisch: Schießgeräusch, Zeitwarnung; Haptisch: Vibration manchmal |
| Raum und Körper: Wie wurden Entfernung, Größe, Reichweite und Körperbewegung berücksichtigt? | 360°, komplettes Tracking im Raum, beide Hände, Wände als Begrenzung, dahinter virtuell, beliebige Bewegung im Raum |
| Präsenz: Wodurch wurde das Gefühl räumlicher Anwesenheit unterstützt oder unterbrochen? | Starke Präsenz, Raum wird berücksichtigt, man muss sich bewegen |
| Komfort und Zugänglichkeit: Welche Belastungen oder Nutzungshürden wurden festgestellt? | - |
| Vermutete Ursache: Wodurch könnte die Beobachtung erklärt werden? | - |
| Gestaltungskriterium: Welche Anforderung wird daraus abgeleitet? | Wände, Boden, Gegenstände etc. werden berücksichtigt; Feedback (visuell, akustisch, haptisch); intuitive Bedienung und Gestaltung (z. B. Pistole ist klar erkennbar in der Funktion); „Gamification“/Spaß; zeitliche Begrenzung, Herausforderung, Score |

## Station 2 – First Steps

| Feld | Eintrag |
| --- | --- |
| Anwendung und untersuchte Situation | Einführung in Bedienung, Wie greift man etc. |
| Eingabeform und verwendete Funktion | Controller, Greifen, Trigger zum Auslösen, beidhändige Interaktion |
| Konkrete Beobachtung: Welche Handlung wurde ausgeführt, und welche Reaktion wurde wahrgenommen? | Rakete, Pin ziehen; Zeppelin steuern; Tischtennis; Papierflieger etc.; Tanzen |
| Handlungsmöglichkeiten: Wodurch wurde die mögliche Aktion erkennbar gemacht? | Visuell: Text, Optisch: Objekte werden hervorgehoben, Akustisch: Audio-Anweisungen |
| Feedback: Welche visuellen, akustischen oder haptischen Rückmeldungen wurden gegeben? | Geräusche, Objekte bewegen sich, Welt ändert sich bei Gamekonsole |
| Raum und Körper: Wie wurden Entfernung, Größe, Reichweite und Körperbewegung berücksichtigt? | Tanzen: Körperbewegung gefordert, ansonsten normales volles Tracking, eher orientiert in eine Haupt-Richtung |
| Präsenz: Wodurch wurde das Gefühl räumlicher Anwesenheit unterstützt oder unterbrochen? | VR -> Ablage, Referenzpunkt an dem man steht, Roboter reagiert/interagiert mit Nutzer |
| Komfort und Zugänglichkeit: Welche Belastungen oder Nutzungshürden wurden festgestellt? | Tischtennis ungewohnt in Bedienung |
| Vermutete Ursache: Wodurch könnte die Beobachtung erklärt werden? | Ausrichtung Controller zu virt. Objekt ist ungewohnt |
| Gestaltungskriterium: Welche Anforderung wird daraus abgeleitet? | Orientierung virt. Objekt <-> Controller ist wichtig |

## Station 3 – Elixir

| Feld | Eintrag |
| --- | --- |
| Anwendung und untersuchte Situation | Magische Welt |
| Eingabeform und verwendete Funktion | Hand-Tracking |
| Konkrete Beobachtung: Welche Handlung wurde ausgeführt, und welche Reaktion wurde wahrgenommen? | Teleportieren -> Bewegung in virtueller Welt, Hände verzaubern -> Funktionen z. B. durch Faust machen ausgelöst |
| Handlungsmöglichkeiten: Wodurch wurde die mögliche Aktion erkennbar gemacht? | Audio-Tutorial, Animationen führen Funktionen vor |
| Feedback: Welche visuellen, akustischen oder haptischen Rückmeldungen wurden gegeben? | Akustisch: Sprach-Anweisungen, Visuell: Reaktionen auf Gesten, Animationen, keine haptischen Reaktionen, weil ohne Controller |
| Raum und Körper: Wie wurden Entfernung, Größe, Reichweite und Körperbewegung berücksichtigt? | Wegen Hand-Tracking ist die Anwendung sehr auf Körperbewegungen angewiesen, einzelne Finger werden getrackt |
| Präsenz: Wodurch wurde das Gefühl räumlicher Anwesenheit unterstützt oder unterbrochen? | Nur Teleportieren, nicht im Raum frei bewegen |
| Komfort und Zugänglichkeit: Welche Belastungen oder Nutzungshürden wurden festgestellt? | Man sollte funktionierende Hände haben |
| Vermutete Ursache: Wodurch könnte die Beobachtung erklärt werden? | - |
| Gestaltungskriterium: Welche Anforderung wird daraus abgeleitet? | Klare Anzeige, was gerade "ausgerüstet" ist, Animationen, die die Funktion erklären -> macht es intuitiver |

## Weitere Gestaltungskriterien

- Sicherheit: Keine plötzlichen Bewegungen erfordern
- Nicht zu viele Effekte auf einmal
- Keine Objekte, zu denen man sehr lange hochschauen muss
- Möglichst natürliche Kopfhaltung
- Entweder virtuelle Welt ist komplett begehbar oder Teleportieren ist implementiert
- Teleportieren: Wie wird Position in Begrenzung angezeigt?
- Controller sollten nicht sehr eng zueinander gebracht werden müssen
