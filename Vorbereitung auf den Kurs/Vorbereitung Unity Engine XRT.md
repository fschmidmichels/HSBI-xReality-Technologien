### Vorbereitungsaufgaben für die Praxisphase vor Beginn des Wintersemester

Studiengang: Software Engineering

Modul: xReality Technologien

Autor: Fabian Schmid-Michels, M.Sc., 2026

Im kommenden Semester sollen XR-Anwendungen mit der Unity Engine programmiert werden.

## Lernziele

Zu Hause erarbeiten Sie sich die Bedienung der Unity Engine und von Visual Studio (Alternativ Visual Studio Code oder andere IDE die mit Unity benutzt werden kann). Sie können ein Projekt erstellen und 3D Objekte platzieren und manipulieren. Sie können ein einfaches Skript erstellen.

## Voraussetzungen

Sie benötigen einen Computer mit folgenden Systemanforderungen:

OS: Windows 10 (64-Bit-Versionen)/ 11, macOS 11+, Ubuntu 24.04 (kann natürlich prinzipiell auch auf anderen Distros laufen, es gibt eine .deb und eine .rpm)
GPU: Grafikkarte mit DX10 (Shader-Modell 4.0)-Fähigkeiten.

Die XR-Hardware wird Ihnen im Digitallabor in der Schulstraße 10 Anfang der Theoriezeit ausgeliehen.

## Installation (ca. 30-60 Minuten)

1. Erstellen Sie sich einen neuen Account „Unity ID“
   <https://id.unity.com/account/new>
2. Laden Sie den *Unity Hub* herunter und installieren Sie das Programm (Der Hub verwaltet die Lizenz, Ihre Projekte und die verschiedenen Installation der Unity Engine)
   <https://unity.com/de/download>
3. Sie werden aufgefordert eine Lizenz anzugeben. Melden Sie sich mit Ihrem vorher erstellten Konto an und aktivieren Sie Pro Lizenz im Unity Hub mit der Seriennummer, die in ILIAS publiziert ist. Es ist jedoch auch möglich den Kurs mit der kostenlosen Personal-Lizenz zu absolvieren.
4. Laden Sie sich die 6000.3.18f1 LTS Version von Unity herunter:
   <https://unity3d.com/get-unity/download/archive> (Diese Version wird auch auf den Computern im Digitallabor installiert sein, bitte achten Sie auf die genaue Nummer!)
5. Wählen Sie im Installationsmenü auch Visual Studio (falls sie nicht VSCode benutzen wollen), Android inkl. JDK/SDK (für die Meta Quest) und den Windows Build Support aus (bzw. auch andere, wenn Sie für andere Systeme entwickeln möchten). Es ist jedoch auch im später möglich die Komponenten nach zu installieren.
6. (nur Windows und Mac) Meta Horizon Link installieren <https://www.meta.com/de/quest/setup/>
7. (nur Windows und Mac) Meta Quest Developer Hub installieren <https://developers.meta.com/horizon/documentation/unity/ts-mqdh/?locale=de_DE> (in der rechten Leiste finden Sie dort den Link für Windows bzw. Mac)

Während der Installation können Sie sich über die Unity Engine informieren oder Literatur oder Videos anschauen

[https://de.wikipedia.org/wiki/Unity\_(Spiel-Engine)](https://de.wikipedia.org/wiki/Unity_%28Spiel-Engine%29)

## Unity Learn

Im Unity Hub finden Sie unter dem Menüpunkt Learn verschiedene Lernprojekte, weitere finden Sie auf <https://learn.unity.com/> .

## Vorbereitungsaufgaben

1. Bitte absolvieren Sie zuerst „Pathway Unity Essentials“ – ca. 10 Stunden. Sie können den 2D Teil gerne überspringen. Im Kurs werden die zentralen Grundlagen für die Arbeit mit Unity vermittelt, sodass der Editor sicher bedient und einfache interaktive Szenen erstellt werden können. Es werden Projekte angelegt, GameObjects in Szenen platziert und mit Komponenten wie Transform, Collider oder Renderer ausgestattet. Außerdem werden grundlegende C#‑Skripte erstellt, um Verhalten zu steuern, einfache Physik zu nutzen und Objekte zu bewegen. Abschließend wird gezeigt, wie Audio eingebunden und ein lauffähiger Build des Projekts erzeugt wird.
   <https://learn.unity.com/pathway/unity-essentials>
2. Lernen Sie etwas über Versionskontrolle
   <https://learn.unity.com/pathway/junior-programmer/unit/manage-scene-flow-and-data/tutorial/set-up-version-control>
3. Aufgabe – Selbst kreativ werden (ca. 6h)
   Mit den erlernten Kenntnissen erstellen Sie ein neues Projekt und bauen einen einfachen Raum mit Innenausstattung, in dem Sie auch einige (kostenlose!) Modelle aus dem Unity Asset Store platzieren. Schreiben Sie mindestens ein Skript selbst, welches die Umgebung ändert. Sie könnten z.B. eine Lichtquelle steuern oder die Farbe eines Gameobjekts ändern.
4. Skript lesen (siehe ILIAS)
